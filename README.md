# Henrique Back

Building AI for science, and keeping it honest.

I'm a postdoc at the Institute of Mathematics and Statistics, UFRGS (Brazil), based in Berlin. I work on machine learning for ocean data, mostly wave forecasting, and on using language models and topic modelling to map the scientific literature.

I use AI a lot in my own research, and I try to be clear about where it helps and where it doesn't. Some of these repos include the instructions and skills I use to work with AI coding agents.

**Projects**

- [wave_forecast](https://github.com/henrique-back/wave_forecast): transformer models for forecasting directional wave spectra from buoy data
- [manuscript-template](https://github.com/henrique-back/manuscript-template): a manuscript structure with Claude Code skills for writing and checking citations
- [mpl_topics](https://github.com/henrique-back/mpl_topics): topic modelling of the marine plastic literature (Scopus, NER, BERTopic)
